# ACCT689 Exam Prep Quiz

Single-file static web app (index.html). No build step, no dependencies. Works on phone and laptop; progress is saved in the browser (localStorage) of each device.

## Deploy to Vercel via GitHub (3 steps)
1. Create a new GitHub repository (e.g. `acct689-exam-prep-quiz`) and upload ALL files in this folder (index.html, vercel.json, package.json, README.md). Keep index.html at the repo root.
2. In Vercel: Add New Project → Import the GitHub repo → Framework preset "Other" → leave Build Command and Output Directory empty → Deploy.
3. Open the Vercel URL on your phone and laptop. Add to Home Screen on iPhone/Android for an app-like icon.

Any later edit to index.html pushed to GitHub redeploys automatically.
